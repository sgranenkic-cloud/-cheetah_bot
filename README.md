# Cheetah.Club Telegram Bot

Инфо-бот для Telegram на aiogram.

## Что делает бот
- Показывает приветственное сообщение по `/start`
- Даёт 4 кнопки меню:
  - Стать настоящим гепардом
  - Что нужно, чтобы начать бегать?
  - Где проходят занятия
  - Какая стоимость занятий
- В разделе "Стать настоящим гепардом" показывает кнопки:
  - Написать тренеру
  - Заполнить форму

## Railway
1. Загрузи файлы в GitHub.
2. В Railway создай проект через Deploy from GitHub Repo.
3. В Variables добавь:
   - BOT_TOKEN = токен от BotFather
4. Убедись, что используется Nixpacks.
5. Перезапусти деплой.

## Важно
Если Railway визуально переносит токен на две строки, это может быть только перенос отображения.
В коде используется очистка токена через:

token = "".join(token.split())

Поэтому пробелы, табы и переносы строки будут убраны автоматически.
